Merged PR Types

Who is contributing

Headcount rather than event counts: a six-person organisation and a one-person organisation can file the same number of PRs.

Who reviews whom

Review is where organisations actually meet. Cells on the diagonal are organisations reviewing their own PRs; everything off it is cross-organisation effort. Cells always show the PR count — the switch changes what the colour means: normalised by row, where each organisation directs its reviewing; by column, where each organisation's review comes from.

Review outcomes

Whether reviews approve, request changes, or just comment.

What contributors get back

How long a PR waits for its first review and for merge, by the organisation that opened it.

Code volume

Totals are dominated by large generated or vendored changes, so the median PR size sits alongside them.

Methodology

Data collected from the GitHub API via PyGithub, covering activity in the 6 months prior to 2025-07-21 across the following repositories: anemoi, anemoi-core, anemoi-datasets, anemoi-inference, anemoi-transform, anemoi-utils.

Bot accounts and automated code agents are excluded from all charts on this page (they remain in the archived JSON).
