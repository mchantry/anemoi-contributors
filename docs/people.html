Methodology

Built from the same cached GitHub data and the same 6-month window as the organisation view, across anemoi, anemoi-core, anemoi-datasets, anemoi-inference, anemoi-transform, anemoi-utils. A merged PR is credited to its opener, every commit author and every Co-authored-by: GitHub user; co-authors known only by email address are left out, as they have no public profile to show. PRs reviewed counts distinct PRs, not review comments, and never a person's own PR. Bots and code agents are excluded throughout.
